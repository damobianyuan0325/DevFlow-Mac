# DevFlow 0.2.0-preview.5

2026-11-05。App 数字版本0.2.0，devflow-record技能1.0.2。当前源码版本；同版GitHub安装包与技能ZIP尚未发布。

## 改动

- 完整JSON及监督计划的字节上限由8 MiB提升至64 MiB，90%容量提示；原路径导入无需删历史或重写哈希。
- 原生「测试与验收 → 执行证据 → 单独核验」及 `DevFlowEvidence inspect-execution <包> <执行ID>` 提供单次执行独立证据核验。
- 结果明确限定为所选计划及本次读取的文件，不冒充最新执行、项目验收或问题闭环。

## 验证入口与边界

`bash scripts/test.sh` 包含超过8 MiB有效监督计划的完整导入、刷新、历史快照、保存重开、原失败/摘要保留与坏输入保护；另覆盖64 MiB准入边界和历史预算耗尽后的单独核验、日志篡改、失败及不存在ID。构建、实际CLI与原生客户端分别验收，证据留在本地。

64 MiB不是无限容量。records最多5000，监督图每类5000/总20000，核验预算1024文件、单文件4 MiB、累计32 MiB继续生效。完整分片归档、跨归档汇总尚未实现；保留完整包及证据的归档副本可单独导入/核验。旧文件缺失或源码变化仍为缺证/过期，不重写历史身份。未完成Developer ID签名或Apple公证。
