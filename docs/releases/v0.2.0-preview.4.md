# DevFlow 0.2.0-preview.4

2026-11-05。App数字版本0.2.0，源码构建版本0.2.0-preview.4，devflow-record技能版本1.0.1。保持已有数据协议和历史；升级前退出应用并备份工作区。此说明记录源码版本，GitHub同版DMG与技能ZIP尚未发布。

## 改动

- 测试、执行、验收、问题和交付等监督列表分页，卡片内长关联与源码列表也分页；历史可完整翻页，关联对象可直接定位。
- 刷新保留上一份同项目监督结果；后台保存工作区，减少界面线程上的编码与磁盘操作。
- 侧栏固定监督入口；主要可点击区域采用macOS原生小手光标区域，保留禁用、键盘和辅助功能语义。
- 有限文件预算优先分配给各用例最新候选；历史全部保留，预算不足明确显示未知。问题复验诊断指出层级、时间或证据不适用的原因。
- JSON接近8MiB时提醒，超过上限说明容量及保留完整历史的处理方式。

## 验证与限制

本轮开发已执行62项核心检查和5项生产AppStore状态检查，并完成本地构建及ad-hoc签名核验。原生检查包括大型真实项目的测试翻页、执行末页和关联定位；私人资料和截图不随源码发布。版本提交前重新检查的结果以交付报告为准。

工具调用耗时不是纯渲染性能基准；不承诺任意数据规模的响应上界。自动化没有独立hover接口，悬停形态和移出恢复未作为全面原生验收。仍有8MiB及证据读取预算；完整分片归档和公共投影工具尚未实现。没有Developer ID签名或Apple公证，没有自动升级。
