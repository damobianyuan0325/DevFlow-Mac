App 数字版本仍为 0.2.0，发布标识为 0.2.0-preview.3。当前托管仓库为 [DevFlow-Mac](https://github.com/damobianyuan0325/DevFlow-Mac)。

安装和接入见 [AGENT_INSTALL](../../AGENT_INSTALL.md)，版本与历史归档见 [版本规则](../VERSIONING.md)。
