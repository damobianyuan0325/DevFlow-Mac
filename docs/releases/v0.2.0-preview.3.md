# v0.2.0-preview.3

DevFlow 是原生 macOS AI 辅助研发过程管理与监督客户端，采用 MIT 许可证。App 数字版本为 `0.2.0`，发布标识为 `0.2.0-preview.3`。

- 提供 Apple Silicon / macOS 14+ 的 DMG 安装包、独立技能 ZIP 和 SHA-256 校验清单。
- App 内置 `devflow-record`、`devflow-resolve`、离线指南与 `DevFlowEvidence` CLI；使用安装包无需 Swift 工具链。
- 完善下载、安装、版本和 AI 接入说明，可将仓库链接或完整技能包交给开发智能体使用。
- 应用功能和本地数据协议没有变更。

安装和接入见 [AGENT_INSTALL](../../AGENT_INSTALL.md)，版本对应与核验见 [版本规则](../VERSIONING.md)。

本版采用 ad-hoc 本地签名，未完成 Developer ID 发行签名或 Apple 公证；首次下载启动可能需要按用户指南确认打开。构建、挂载复制、CLI 和下载核验结果见 [Release 验证记录](https://github.com/damobianyuan0325/DevFlow-Mac/releases/tag/v0.2.0-preview.3)。
