# DevFlow 0.2.0-preview.8

2026-11-06。App 数字版本 0.2.0，支持 Apple Silicon、macOS 14+，内置 devflow-record 1.0.4 和 devflow-resolve。

## 本次变化

- 单个明确关联的 Codex JSONL 会话读取上限由 32 MiB 提升到 200 MiB；超过时仍提示只读取前缀。
- 延续监督工作台、静默刷新、分页、历史执行单独核验及执行状态区分。
- 更新安装、版本和智能体接入说明，提供 DMG、技能 ZIP 和 SHA-256 清单。

## 限制

单会话最多 20,000 个事件，单事件文本限制 64 KiB；这些限制独立生效，字节上限提升不代表所有长聊天都完整覆盖。未接入、密文、隐藏推理和截断内容依然不可见。200 MiB 会话的资源消耗可能较高；无自动分片归档。

App 仅为 ad-hoc 签名，未完成 Apple Developer ID 签名与公证，首次启动请按用户指南操作。无 Intel/Universal 安装包。
