# v0.2.0-preview.2

App数字版本0.2.0，安装交付版本0.2.0-preview.2，固定同名tag。preview.1保留。

- 新增Apple Silicon DMG：App拖到Applications即可复制安装。
- App内部包含完整devflow-record/devflow-resolve技能、离线说明、BUILD-INFO和证据CLI，卸载安装卷后仍可读取。
- App菜单支持打开技能目录、复制真实接入路径给AI。不会自动修改其他AI宿主配置。
- 同版本独立技能ZIP便于分享；源码归档与用户安装包分开列出。

入口见[安装与接入](../../AGENT_INSTALL.md)。本版最初在Private仓库发布；2026-10-30项目转为MIT开源，现可公开下载。仍采用ad-hoc签名，未Apple公证，不保证独立Mac无警告启动；既有tag和附件保持不变。真实构建、挂载复制、CLI/UI及下载核验结果以GitHub Release说明为准。
