# DevFlow 0.2.0-preview.6

2026-11-05。App数字版本0.2.0，devflow-record技能1.0.3。源码版本；同版GitHub安装包与技能ZIP尚未发布。

## 执行状态显示修正

执行卡片和单独核验弹窗分别呈现核验结论、记录结果和实际退出码。未知结果与非零退出并存时使用橙色「核验未通过 · 非零退出」，说明产品运行结果仍须结合命令约定和日志核对。明确失败记录或失败计数用红色区分；通过声明与非零退出显示冲突。

聚合failed中文标签改为「核验未通过」。机器state=failed、有效通过、最新执行和问题闭环规则保持不变，没有为exitCode=3或业务日志中特定文字增加放行逻辑。未知计数继续保留未知。

## 验证与边界

核心回归覆盖unknown/blocked/notRun/passed/failed与多种非零码、未知/零退出、失败计数和新未知执行不能被旧成功掩盖；原生检查分别覆盖执行卡片和单独核验入口。具体运行输出保留本地，不发布真实项目数据。测试脚本显式构建并验证debug CLI的10 MiB合同入口，App和开发工具身份分别核对。

延续preview.5的64 MiB及其他记录/证据预算；没有自动分片归档。没有Developer ID签名、公证或自动升级。本次不修改导入项目的账本、源码或服务。
