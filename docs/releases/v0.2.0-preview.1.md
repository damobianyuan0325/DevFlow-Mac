# DevFlow v0.2.0-preview.1

首个 GitHub **pre-release**，对应 App 数字版本 **0.2.0**。仓库保持 **Private**，源码、Release 和资产只对获授权账号可见。[固定 Release 页](https://github.com/damobianyuan0325/DevFlow/releases/tag/v0.2.0-preview.1) 提供该版本的下载入口与验证记录。

这是 Apple Silicon 的原生 macOS 预览，最低构建目标 macOS 14。应用为 **ad-hoc 本地签名，未完成 Developer ID 发行签名或 Apple 公证**。下载后可能受到系统启动限制；不能把本版称为稳定版或无需系统提示的正式安装包。

## 本版内容

- 只读导入 Markdown、schemaVersion=1 历史包及 schemaVersion=2 监督包，保留来源、未知时间、失败和历史修订。
- 统一需求、验收、任务、测试设计、每次执行、问题、修复复验与交付；提供阶段简报及介入对象。
- 核对当前证据的合同、源码、日志、版本、层级与计数，区分已满足、缺证、过期和失败；声明修复不等于有效关闭。
- 手选 Codex JSONL，单独导入或为项目关联最多 8 个会话，查看已支持的公开动作与覆盖限制。
- 提供搜索、类型和事件日期筛选、来源查看、反馈编辑/保存/复制、前台读取及暂停控制。
- 内置明确标注的合成教学复盘样本，公开文档和技能不需要访问私人研发记录。
- 提供独立可用的 `devflow-record`、`devflow-resolve`；`gated-delivery` 仅作显式选择的可选适配，客户端不会自动调度。

## 版本绑定

- `VERSION`：`0.2.0`；`REL_VERSION`：`0.2.0-preview.1`。
- 集成分支：`main`；版本维护分支：`codex/release/0.2`。
- 固定 tag：`v0.2.0-preview.1`，对应精确源码提交，交付后不移动。
- `0.1.0`、`0.1.1` 保留为早期本地研发历史，不补造 GitHub tag/Release。

若需修正代码或产物，应创建新预览序号，保留旧版及其限制，详见 [版本规则](../VERSIONING.md)。

## 验证范围与当前限制

本版核对范围分为当前源码自动化检查、技能检查、原生应用观察、包内容和签名完整性、远端版本及资产核对。具体检查结果见 [同版本 GitHub Release 验证记录](https://github.com/damobianyuan0325/DevFlow/releases/tag/v0.2.0-preview.1)；已声明的未验层保持明确，上传完成不等于产品验收通过。

尚未完成的发行条件包括 Developer ID 签名、Apple 公证、独立下载机器首次启动与完整兼容性验证。当前没有 Intel/Universal 下载包、自动升级、云同步、账号、外部模型接入或自动代理控制。应用不运行导入命令，不发送反馈；暂停只影响资料读取。

只展示已接入来源支持的公开动作，不能还原隐藏推理、未接入代理或脚本内部未记录的步骤；费用和用量没有可靠来源时保持未接入。摘要、检查计数与机器状态不构成业务正确性保证。工作区与导出可能包含敏感摘录，请阅读 [隐私说明](../PRIVACY.md)。
