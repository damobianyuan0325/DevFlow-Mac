# DevFlow 0.2.0-preview.7

App 数字版本 0.2.0，支持 Apple Silicon、macOS 14+；本预览面向本地 AI 辅助研发过程监督。下载资产及发布状态以对应 GitHub Release 页面为准。

## 新增与改进

- 监督工作台固定入口，刷新时保留现有页面和结果，改善使用连续性。
- 测试、执行、需求、问题和交付列表分页，工作区保存转入后台。
- 完整监督账本上限提升到 64 MiB；支持在客户端和 CLI 单独核验历史执行。
- 区分记录结果、命令退出码和核验状态；未知结果与非零退出不会被表述为产品运行失败，也不会因此视为通过。
- 按钮、链接和主要交互采用小手光标；附带 devflow-record、devflow-resolve 和证据 CLI。
- 更新安装、使用、版本与智能体接入说明，并提供独立技能包和 SHA-256 清单。

## 限制

本包采用 ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证，首次打开可能需要按用户指南操作。未提供 Intel/Universal 包、自动升级或自动分片归档；64 MiB、记录数量和证据核验预算仍有限。历史结果、退出码和验收通过是不同事实。详见用户指南和监督协议。
