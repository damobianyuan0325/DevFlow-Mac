## v0.2.0-preview.1 · 首个 GitHub 预发布

首个 GitHub Release 使用 `v0.2.0-preview.1`，App 数字版本 `0.2.0`，发布类型为 pre-release。资产是否已发布以 [固定 Release 页](https://github.com/damobianyuan0325/DevFlow-Mac/releases/tag/v0.2.0-preview.1) 为准；范围与限制见 [本版说明](releases/v0.2.0-preview.1.md)。源码和脚本可供独立构建，检查结果须对应实际使用的源码，检查结果不跨版本代用。

- 支持 schemaVersion=2 监督包，在原记录上组织需求、验收、任务、用例、执行、问题与产物；schemaVersion=1 历史资料继续支持。
- 每个项目可手动关联最多 8 个 Codex 会话，公开动作与语义资料在同一项目回查；不扫描全部私有对话，未接入内容保留覆盖边界。
- 测试设计和每次执行分开，核对执行前验收合同、源码/日志身份、版本、层级和实际计数；旧结果、过期与缺少验证分别呈现。
- 保留问题原失败，区分修复声明与有效复验；阶段简报列出已有依据、缺口及手动介入对象。客户端不内置模型推测业务质量。
- 为监督对象生成带依据和限制的反馈草稿，支持编辑、保存、复制；复制不会发送消息或自动关闭问题。
- 前台当前项目每 15 秒读取；可暂停自动资料刷新、停用单个会话并保留最后内容，读取错误明确可见。暂停资料读取不暂停代理。
- 保留先前导入的监督计划快照；无可靠来源的费用、用量或耗时保持未接入。
- 提供可独立使用的 `devflow-record` 与 `devflow-resolve` 技能、协议、模板和隔离运行的教学例子。`gated-delivery` 是显式选择的可选适配；客户端不自动调度技能。
- 提供源码构建的 `DevFlowEvidence` CLI，支持只读 `contracts` 和 `inspect`；当前预览 ZIP 不包含此工具。
- 将可移交文档与本地私人开发记录分开，随仓库内置样本明确使用合成教学内容，不作为真实项目或执行凭据。
- 补齐安装与使用、备份升级、版本维护及发布说明；以 `REL_VERSION` 区分预览发布版本，`VERSION` 保持 App 数字版本。应用 ZIP 与独立技能 ZIP 均带完整技能和公开资料，以 `SHA256SUMS.txt` 核对最终下载字节。

仍为本地 ad-hoc 预览。完整动作采集、Developer ID 发行签名、Apple 公证、独立下载环境验证及自动升级未完成。范围与数据处理见 [试用与分发](RELEASE.md)、[隐私说明](PRIVACY.md)。

## 0.1.1 · 本地研发历史 · 2026-10-30

增加单个 Codex 开发会话接入，并修正导入语义与反馈上下文。

- 修正需求正文中的“失败”、shell 命令 `open`、嵌套验收标题和显式验收状态列的误判；保留旧内容历史快照。
- 反馈附带来源摘录、限制及直接关联记录；“需留意记录”包含历史失败，不作为当前未解决问题总数。
- 接入用户指定的本地 Codex JSONL，显示需求、公开进展、工具调用/结果、命令与文件变更，保留事件时间、来源行号和调用关联；重复刷新不以导入时间制造新动作。
- 记录由开发代理保留一句话需求并完成拆解的约定；客户端没有内置 AI 自动拆解功能。
- 会话导入排除内部推理和配置、过滤二进制、有限遮盖常见敏感值；未接入来源及未记录步骤仍不可见，原始日志不随应用包分发。

本版本为本地研发预览，没有补建对应 GitHub tag 或 Release；其检查与原生观察不能自动覆盖后续版本。

## 0.1.0 · 本地研发历史 · 2026-10-30

初始本地 macOS 研发预览，提供原生项目历史阅读与手动反馈流程；没有补建对应 GitHub tag 或 Release。

- 原生三栏工作台，按项目查看概览、记录、需求、研发、测试、缺陷、决策、交付与反馈。
- 只读导入资料目录、Markdown 文件或 schemaVersion=1 JSON；显示扫描限制、无效输入及来源提示。
- 搜索、按类型及已知日期筛选，未知日期单列；查看摘录、相对位置、版本、来源类别与关联。
- 区分文档记载、执行凭据和事后复盘；不以导入时间填补事件时间，不生成整体质量分。
- 手动刷新及前台当前项目的定期读取，保留修订和缺失记录，失败保留已有内容。
- 编辑、保存、复制反馈；工作区与草稿本地持久化。记录导出不包含反馈草稿。
- 提供内置复盘样本入口、应用图标、本地 `.app` 和不包含用户工作区的预览打包脚本。

初版即采用本地资料边界，不提供账号、遥测、云同步、外部模型、自动发送反馈或代理控制。后续版本继续保留这些边界。
