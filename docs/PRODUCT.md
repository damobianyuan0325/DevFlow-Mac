# DevFlow 产品范围

当前版本：0.2.0 原生 macOS 本地预览。DevFlow 面向使用 AI 辅助开发的个人与小型项目，把需求、实现、检查、失败、修复和交付放在同一条可回查的项目历史中。已有历史与持续新增记录同等重要。

## 用户能完成什么

| 范围 | 当前可观察行为 | 保留的边界 |
| --- | --- | --- |
| 本地导入 | 用户选择 Markdown 资料目录、文件或 JSON 包；保留来源位置、摘录、状态与限制 | 有数量和大小预算；通用文档提取不能重建全部语义 |
| 项目与历史 | 按项目、类型、搜索及已知日期筛选；查看关联、旧失败与内容修订 | 未知日期保持未知；复盘内容不冒充当时已知事实 |
| 需求与任务 | schemaVersion=2 包保留用户原话、拆解、假设、验收、任务和先前导入的计划快照 | 拆解由资料生产者或开发代理提供；客户端不内置模型自动拆解 |
| 测试与验收 | 测试设计、各次执行、真实计数、层级、命令、时间及源码/日志/合同身份分开显示 | 设计存在不等于执行；旧成功不自动适用于当前版本 |
| 问题与交付 | 问题关联标准、回归、修复记录与复验；交付文件关联摘要及执行 | 修复声明不等于有效关闭；摘要一致不证明业务正确 |
| 公开动作 | 手选本地 Codex JSONL；单会话导入，或为项目关联最多 8 个会话 | 只覆盖支持格式中已记录的公开动作，不扫描全部聊天 |
| 阶段简报 | 展示当前目标、有效依据、失败或缺证、介入对象及接入范围 | 不生成整体质量分；没有可靠来源的耗时、费用和用量保持未接入 |
| 反馈 | 从具体问题形成带依据和限制的草稿，编辑、保存、复制 | 用户决定是否发送；复制不表示送达或解决 |
| 刷新与保存 | 手动刷新，前台当前项目每 15 秒读取；可暂停自动读取或停用单个会话；工作区与草稿本地持久化 | 读取失败保留上次内容；无新记录不能推断代理运行状态；暂停读取不控制代理 |
| 本地应用 | SwiftUI/AppKit 界面、图标、空态与错误提示；构建 `.app` 和本地预览 ZIP | ad-hoc 签名，不代表 Developer ID 签名、公证或完整兼容性验证 |

schemaVersion=1 的普通历史资料继续支持。内置复盘样本是明确标注的合成教学内容，不是实际项目数据或执行证明。

## 需求与证据契约

一句话需求应由开发代理保留原话，再拆解目标、假设、范围、可观察验收和有限任务；后续改变要留下版本和原因。代理补充的解释不能冒充用户原话。当前客户端展示这些已提供的语义，不替代业务需求确认。

监督关系使用 R（需求）→ A（验收）→ U/T（任务与检查设计）→ E（实际执行），并连接问题、修复、复验及交付。格式见 [监督协议](supervision-protocol.md)。动作记录中的文档记载、执行凭据与复盘归纳要分开，计划、调用、返回和业务验收也要分别表达。

每次实际检查追加独立 E，保留失败和原身份；执行前固定合同和相关源码。当前有效通过需要相符的要求、源码、日志、层级、候选版本及完整计数。缺失、未知、零和失败不能混用；不能删除旧失败或事后补造时间、计数、合同来满足验收。相关代码或合同改变后，应重新核对适用性。

公开动作包括已接入来源中的需求、进展、工具调用及返回、命令、文件修改与代理报告。实际结构化内层动作可按来源展开；脚本中没有独立记录的步骤不能从文本推断为已经执行。父会话里的子代理报告不代表其完整内部动作已接入。

## 独立技能与用户介入

[devflow-record](../skills/devflow-record/SKILL.md) 负责本地资料生产约定；[devflow-resolve](../skills/devflow-resolve/SKILL.md) 帮助开发代理核对反馈、补证或修复、复验并回写已有资料。两者均可独立使用。`gated-delivery` 只在用户或环境选择时作为可选研发适配。

技能由用户或具备授权的宿主调用。客户端没有自动调度技能、安装技能、发送反馈或启动开发任务的能力。技能配置不会自动形成后台任务，也不扩大原有授权。接入方法见 [代理指南](agent-quickstart.md) 和 [问题处理指南](agent-resolution.md)。

## 产品边界

应用只读导入来源，不修改原项目，不运行资料中的命令，不读取隐藏推理、系统或开发者配置，不自动发现所有会话或未接入子代理。没有外部模型 API、账号、遥测、云同步、自动升级或代理控制。通用 Markdown 和会话格式都有识别边界，未支持或被截断的内容应明确提示。

工作区、备份、导出及剪贴板都可能保存敏感摘录。有限过滤不等于全面脱敏，分享前需核查，见 [隐私说明](PRIVACY.md)。源码托管、公开源代码和正式分发应用是不同交付层；发行条件见 [试用与分发](RELEASE.md)。
