# DevFlow 本地预览版隐私说明

适用版本：0.2.0 本地预览，2026-10-30。本说明描述当前应用的数据边界；正式分发条件见 [试用与分发](RELEASE.md)，不代表隐私认证。

## 数据在本机处理

此版本的应用自身没有账号、遥测、云同步、模型 API 或网络请求功能。导入、搜索、历史整理和反馈草稿在本机处理，不向开发者上传项目资料。

用户选择项目目录、Markdown 文件或 DevFlow JSON 后，应用只读读取允许范围内的材料。schemaVersion=2监督包包含需求、验收、任务、用例、执行、问题及产物关系；应用还会在绑定的资料根内读取相关源码和日志来核对摘要。导入和证据核对有文件类型、数量和大小限制，跳过或无法核对的来源会显示提示。应用不会执行资料里的命令、修改原项目或向 AI Agent 发送任务。

“接入开发会话”每次只读取用户选择的单个 Codex JSONL 文件；也可向当前项目手动关联最多8个会话，不扫描其他聊天。应用提取用户需求、公开进展、实际工具/命令调用和结果、文件变更及代理报告；内部推理、系统与开发者配置、压缩上下文不进入工作区。日志里的图片/音频等二进制载荷不进入摘录，显示内容省略提示。导入器对常见凭据字段和用户目录作有限遮盖，但不保证所有业务机密都已识别。应用内不提供打开原始会话的按钮。

会话日志格式可能改变，也可能在写入中。支持范围、重复/未识别项、读取预算和不完整尾行会在导入结果中说明。只有已记录且已接入的动作可见；未接入子代理或脚本内部未记录的步骤不能还原。应用前台时每15秒重读当前选中项目，内置样本不自动刷新；退出或后台运行不提供持续采集保证。可以暂停自动资料刷新或停用单个会话的读取，仍保留此前内容；暂停不会停止Agent，手动刷新仍可用。

“打开原文件”和“在 Finder 中显示”交给 macOS 及用户的默认应用处理。外部应用的联网或同步行为由其自身设置决定。

## 本地保存的位置与内容

默认工作区文件：

```text
~/Library/Application Support/DevFlow/workspace.json
```

其中保存项目名称、导入和来源目录、会话源绑定位置及读取开关、记录及原文摘录、来源摘要、导入时间、历史版本、监督计划及先前计划快照、限制提示和反馈草稿。执行资料可包括命令、时间、源码/日志身份与产物路径。保存时，前一版工作区备份为同目录下的 `workspace.json.backup`。使用自定义工作区启动参数时，文件及备份保存在所指定的位置。

工作区与备份是普通本地 JSON 文件，应用没有额外加密。文件访问保护依赖 macOS 用户权限及设备的磁盘保护设置。应用没有“所有资料已经脱敏”的自动保证。

## 导出与剪贴板

“导出记录”生成明文 JSON，包含当前聚合记录、关联、来源相对路径和原文摘录；带监督计划的项目还导出计划、测试执行及证据引用。当前导出不包含反馈草稿或本机会话源绑定设置。摘录、命令、路径或反馈可能含项目敏感内容，分享前请检查具体文件；不因有摘要或经过会话过滤就保证全部脱敏。

“复制反馈”将编辑内容写入系统剪贴板，同时保存本地草稿。后续由用户决定粘贴到哪里；应用不自动发送。系统通用剪贴板或其他剪贴板工具的行为由相应设置决定。

## 移除与保留

“从工作台移除”删除当前工作区里的项目记录和该项目的反馈草稿，不删除或改动原始项目文件。前一版备份、已生成的导出文件以及系统剪贴板可能仍保留相应内容；此操作不会一并清除它们。

如需彻底清理 DevFlow 的本地资料，请先退出应用，再处理工作区文件、备份和自己保存的导出文件。保留原始项目目录与否由用户另行决定。

## 预览版边界

内置复盘样本是明确标注的合成教学内容，用于说明记录如何关联；它不含真实项目执行证明，也不代表任何项目当前状态。来源类别、内容摘要或检查通过记录也不能保证业务正确性。本地预览包未完成 Developer ID 发行签名和 Apple 公证，不应将本地签名核验视为对外发行或隐私认证。

监督判断仅针对已接入计划和本地证据。验收约束、源码或日志改变会影响当前适用性；费用、用量或耗时缺乏可靠来源时不补造。应用不联网取得账单，也不调用外部模型补全语义。

## 技能与源码托管

随仓库提供的 `devflow-record` 和 `devflow-resolve` 是交给开发代理阅读的本地说明，可独立使用；可选研发适配仅在用户或环境显式选择时生效。客户端不会自动运行这些技能、安装插件、调度任务或向其他服务发消息。代理宿主自身的数据处理取决于该宿主及用户选择，不能用本应用的本地处理边界替代其隐私约定。

源码托管不包含用户工作区、原始会话或私人验收资料，也不授权公开上传这些内容。可移交样例应使用合成数据；导出的真实项目资料仍需逐份检查摘录、身份和来源权限。报告问题时可参照 [贡献指南](../CONTRIBUTING.md)，避免提交敏感工作区或原始日志。
